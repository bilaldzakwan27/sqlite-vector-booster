# Security reporting

For a potential memory-safety issue, crash with security implications, or other
vulnerability, use GitHub's private vulnerability reporting form when enabled:

https://github.com/bilaldzakwan27/sqlite-vector-booster/security/advisories/new

If private reporting is unavailable, contact the maintainer through the GitHub
profile to arrange a private channel before sending exploit details or sensitive data.
Use public issues for ordinary non-sensitive bugs. Include the affected version,
platform/architecture, minimal synthetic reproducer, impact, and sanitized logs.

The project is pre-1.0. Fixes target the latest maintained release; no guaranteed
response time or long-term support window is currently offered. Do not disclose
credentials, personal records, or proprietary vector datasets in any report.
